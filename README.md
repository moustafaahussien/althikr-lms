# منصة دار الذكر التعليمية (LMS) — المرحلة الأولى: الأساس الموحّد

هذه المرحلة تبني الأساس الذي ستقوم عليه كل وحدات المنصة القادمة (تحضير الدروس، الواجبات، الاختبارات، التحليل…):

- **تسجيل دخول واحد** بحساب Google المدرسي (`@althikr.edu.sa`) — بلا أكواد ولا كلمات مرور.
- **قاعدة بيانات واحدة** (Supabase / PostgreSQL) للطلاب والموظفين والفصول والمواد والإسناد.
- **صلاحيات محمية من الخادم نفسه** (Row Level Security): كل شخص يرى ما يخصه فقط حتى لو حاول التلاعب بالصفحة.
- **صفحة رئيسية لكل دور**، و**لوحة إدارة** كاملة، و**استيراد جماعي** من Excel.

## من يرى ماذا؟

| الدور | ما يراه |
|---|---|
| **مدير النظام** | كل شيء + لوحة الإدارة (إضافة/تعديل/حذف/استيراد) |
| **الإدارة العليا** (الرئيس التنفيذي، مدير التعليم) | كل المدرسة للقراءة + الإحصاءات |
| **مدير مرحلة** | فصول وطلاب مرحلته فقط (حسب النطاق) |
| **مشرف** | ما يحدده نطاقه: مرحلة، أو صفوف معينة، أو مادة، أو مزيج منها |
| **معلم** | الفصول المُسندة إليه فقط وطلابها |
| **طالب** | فصله ومواده ومعلميه، وأسماء زملائه فقط (بدون أي بيانات تواصل) |
| **ولي أمر** | أبناؤه فقط (تُفعَّل بالكامل في مرحلة لاحقة) |

> **خصوصية قسم البنات:** معلم أو مشرف قسم البنين لا يرى أي بيانات من قسم البنات إلا إذا أُعطي نطاقًا صريحًا عليه.

### أمثلة على النطاقات

| الشخص | النطاق |
|---|---|
| مدير المرحلة الابتدائية بنين | المرحلة: `ابتدائي بنين` |
| مشرف الصفوف الأولية (بنين وبنات) | نطاقان: `ابتدائي بنين` من صف 1 إلى 3 + `ابتدائي بنات` من صف 1 إلى 3 |
| مشرف العلوم للمدرسة كلها | المادة: `العلوم` |
| مشرف العلوم للمتوسط فقط | المرحلة: `متوسط بنين` + المادة: `العلوم` |
| مشرف الدبلوم الأمريكي | المرحلة: `الدبلوم الأمريكي` |

## خطوات الإعداد (مرة واحدة)

### الخطوة 1: إنشاء مشروع Supabase
1. ادخل إلى <https://supabase.com> واضغط **Start your project**، وسجّل الدخول بحساب GitHub.
2. اضغط **New project**:
   - **Name:** `althikr-lms`
   - **Database Password:** اضغط **Generate**، ثم **احفظ كلمة المرور في مكان آمن**.
   - **Region:** اختر أقرب منطقة متاحة (مثل Frankfurt أو Mumbai).
3. اضغط **Create new project** وانتظر دقيقة أو دقيقتين حتى يجهز.

### الخطوة 2: إنشاء قاعدة البيانات
1. من القائمة الجانبية افتح **SQL Editor**، ثم اضغط **New query**.
2. افتح الملف `sql/01_schema.sql`، وانسخ محتواه كاملًا، والصقه، ثم اضغط **Run**. يجب أن تظهر رسالة **Success**.
3. افتح **New query** جديدًا، ونفّذ الملف `sql/02_security.sql` بنفس الطريقة.
4. افتح الملف `sql/03_seed.sql` وعدّل السطر الأخير: ضع **بريدك المدرسي الحقيقي** بدل `YOUR_EMAIL@althikr.edu.sa`، ثم نفّذه.

> تشغيل الملفات مرة ثانية آمن ولا يكرر البيانات.

### الخطوة 3: ربط الدخول بحساب Google المدرسي
**أ) في Google Cloud** (ادخل بحسابك المدرسي):
1. افتح <https://console.cloud.google.com> ← من أعلى الصفحة اختر **New Project** باسم `Althikr LMS` ← **Create**.
2. من القائمة افتح **APIs & Services ← OAuth consent screen** (في الواجهة الجديدة اسمها **Google Auth Platform**):
   - اضغط **Get started** واكتب اسم التطبيق `منصة دار الذكر التعليمية` وبريد الدعم.
   - **Audience / User type:** اختر **Internal**. هذا يجعل الدخول مقصورًا على حسابات المدرسة فقط.
     - إذا لم يظهر لك خيار Internal، فهذا يعني أن حسابك لا يملك صلاحية على مؤسسة Google Workspace الخاصة بالمدرسة. في هذه الحالة اختر **External** ثم **Publish app**. قاعدة البيانات نفسها سترفض أي بريد من خارج المدرسة.
3. افتح **Credentials ← Create credentials ← OAuth client ID** (أو **Clients ← Create client**):
   - **Application type:** `Web application`
   - **Authorized redirect URIs:** أضف الرابط التالي: `https://<PROJECT-ID>.supabase.co/auth/v1/callback`
     - تجد `<PROJECT-ID>` في رابط مشروعك على Supabase، أو في **Project Settings ← General ← Project ID**.
   - اضغط **Create**، ثم انسخ **Client ID** و**Client Secret**.

**ب) في Supabase:**
1. افتح **Authentication ← Sign In / Providers ← Google** ← فعّله ← الصق **Client ID** و**Client Secret** ← **Save**.
2. افتح **Authentication ← URL Configuration**:
   - **Site URL:** رابط المنصة على GitHub Pages، مثل `https://moustafaahussien.github.io/althikr-lms/`
   - **Redirect URLs:** أضف `https://moustafaahussien.github.io/althikr-lms/index.html`

### الخطوة 4: إعداد ملف `config.js`
1. في Supabase افتح **Project Settings ← API** (أو **API Keys**).
2. انسخ **Project URL** والمفتاح العام (**anon public**، أو **Publishable key** في المشاريع الجديدة).
3. افتح `assets/js/config.js` وضع القيمتين مكان `SUPABASE_URL` و`SUPABASE_ANON_KEY`.

> ✅ المفتاح العام آمن في الصفحة لأن الحماية في قاعدة البيانات نفسها.
> ⛔ **لا تضع أبدًا** مفتاح `service_role` أو `secret` في أي ملف من ملفات الموقع.

### الخطوة 5: النشر على GitHub Pages
1. ارفع المشروع إلى مستودع على GitHub.
2. افتح المستودع ← **Settings ← Pages** ← **Source: Deploy from a branch** ← **Branch: main / (root)** ← **Save**.
3. بعد دقيقة افتح رابط المنصة وادخل بحسابك المدرسي.

## تجهيز البيانات (بالترتيب)

من **لوحة الإدارة ← الاستيراد**:

1. **الموظفون** أولًا (المعلمون، المشرفون، مديرو المراحل، الإدارة العليا) مع نطاقاتهم.
2. **الطلاب** (الفصول الناقصة تُنشأ تلقائيًا).
3. **الإسناد**: من يدرّس ماذا لأي فصل.

لكل نوع:
1. اضغط **تنزيل القالب** لترى شكل الأعمدة، أو ارفع ملفك كما هو.
2. اربط كل حقل بالعمود المقابل في ملفك. إذا كان الحقل ثابتًا لكل الصفوف (مثل ملف لمرحلة واحدة)، اختر **قيمة ثابتة** واكتبها.
3. اضغط **تحقق بدون حفظ**. ستظهر الأخطاء برقم الصف في ملف Excel.
4. صحّح الأخطاء، ثم اضغط **استيراد وحفظ**.

> **إعادة الاستيراد آمنة:** الطالب يُعرف برقمه، والموظف ببريده. لذلك إعادة رفع الملف تحدّث البيانات ولا تكررها.
> اضغط **أسماء المراحل والصفوف المعتمدة** لتنزيل الأسماء المقبولة بالضبط.

**الأدوار المقبولة في ملف الموظفين:** مدير نظام، قيادة، مدير مرحلة، مشرف، معلم/معلمة، موظف، ولي أمر.
**المراحل:** ابتدائي بنين، متوسط بنين، ثانوي بنين، ابتدائي بنات، الدبلوم الأمريكي.

## مهام يومية

| المهمة | الطريقة |
|---|---|
| إضافة معلم جديد | الموظفون ← **إضافة موظف**. أو أضف صفه في ملف Excel وأعد الاستيراد |
| إعطاء مشرف صلاحية مرحلة أو مادة | الموظفون ← **تعديل** ← النطاقات ← **إضافة نطاق** |
| إيقاف حساب دون حذفه | **تعديل** ← الحالة: **موقوف** (يُمنع من الدخول فورًا) |
| نقل طالب أو مجموعة طلاب لفصل آخر | الطلاب ← حدّد الطلاب ← **نقل المحددين** |
| بداية عام دراسي جديد | الأعوام الدراسية ← أضف العام والفصل واجعلهما **الحالي** ← أعد استيراد الطلاب بفصولهم الجديدة ← استورد الإسناد مع خيار **حذف كل الإسنادات الحالية** |
| معرفة من غيّر ماذا | **سجل التغييرات** |

## حل المشكلات

| المشكلة | الحل |
|---|---|
| «المنصة لم تُربط بقاعدة البيانات» | لم تعدّل `config.js` بعد (الخطوة 4) |
| «الحساب غير مسجّل في المنصة» | البريد غير موجود في الموظفين أو الطلاب، أو الحساب موقوف |
| خطأ `redirect_uri_mismatch` من Google | رابط callback في Google Cloud لا يطابق رابط مشروع Supabase (الخطوة 3-أ) |
| الدخول ينجح ثم يعود لصفحة الدخول | أضف رابط `index.html` في Redirect URLs في Supabase (الخطوة 3-ب) |
| معلم لا يرى فصوله | تأكد من وجود إسناد له في تبويب **الإسناد** |
| مشرف لا يرى شيئًا | أضف له **نطاقًا** من تبويب الموظفين |
